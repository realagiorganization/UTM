# Assumptions

- The BDD suite is implemented as a lightweight documentation-style test using `behave`, since running full iOS/macOS UI automation is not feasible in this environment.
- The BDD VHS recording is generated by the GitHub Actions workflow and committed back into the repo as `automation/vhs/bdd.gif` when the workflow runs.
- The GitHub Pages smoke test for 2026-01-30 reuses the provided Discord attachment screenshots as the authoritative capture set.
